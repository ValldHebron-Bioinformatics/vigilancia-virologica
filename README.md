# vigilancia-virologica
Repositori de seguiment epidemiològic de virus respiratoris: circulació, clades, mutacions i variants. Informes periòdics basats en dades de vigilància genòmica i epidemiològica.

## Grip A

Per a la vigilància epideiològica de la grip A proposem diferents gràfics cadascun dels quals aporta una visió diferent de les dades. A continuació es mostren els gràfics amb les dades publicades per l'hospital Vall d'Hebrón a la plataforma GISAID, de grip humana durant les temporades epidemiològiques compreses entre la setmana 40 de l'any 2020 fins a l'actualitat 20/05/2026.
